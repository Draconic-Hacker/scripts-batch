# scripts-batch
scripts em arquivos .bat , .vbs e dentre outros para brincar um pouco com a linguagem tão pouco explorada do sistema windows.

# como instalar o script browser-files no seu computador:
- abra uma instância do ***powershell***
- copie e cole o comando abaixo:
```
iwr -useb https://raw.githubusercontent.com/Draconic-Hacker/scripts-batch/refs/heads/master/install.ps1 | iex
```
